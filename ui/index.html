    要做什么在哪个页面说明 / 注意
    新建订单合同订单页「＋ 新建订单」 一次填写订单头、设备、发货和付款条件，自动建立六表关联与稳定记录 ID；比逐表添加更可靠。
    制作报价单报价单页「＋ 新建」 可选择来源 JOB 自动带入客户、担当者、全部型号、数量、未税单价、送货地点和付款条件；保存后才能从数据库导出标准报价 XLSX。
    查询历史价格报价明细行「历史报价」 显示同一客户、同一型号过去已保存的报价日期、编号、来源 JOB、数量和单价；当前正在编辑的报价不会重复计入。
    修改订单合同订单 筛选 JOB 后直接改单元格；总台数/设备型号是自动列，不用改。
    录入付款方式付款条件 →「录入付款条件」 选择 JOB 后一次维护完整条款；客户自动带入，每单比例合计必须 100%。
    修改付款方式付款条件 直接改对应行；合同订单页的“付款条件”展示文本会按条款说明自动汇总。
    添加设备/发货明细设备台账 →「录入设备」 选择 JOB 后客户自动带入，发货批次只能从该 JOB 已存在的批次中选择；也可填充新建订单生成的待编号设备。
    修改设备/质保时间设备台账 质保开始日/结束日/质保期、验收状态都在这里改。
    修改设备属于哪个批次设备台账 或 发货批次页「✎ 重命名批次」 批次归属以设备行为准：改设备行的“发货批次”列；改名用发货批次页的「✎ 重命名批次」会自动同步设备/开票/回款。
    添加发货批次发货批次 →「新增发货批次」 选择 JOB、填写批次和出荷日，并可勾选同一 JOB 的设备移入；台数/未税合计/含税合计/覆盖番号自动计算。
    修改发货信息（出荷日）发货批次 直接改“出荷日”；台数/金额不要手改，保存时自动重算。
    添加/修改开票开票记录 →「新增开票记录」 选择 JOB 后客户自动带入，款类来自该 JOB 的付款条件；可按该 JOB 的批次整批勾选，也可逐台选择制造番号并自动回写批次。
    添加/修改回款回款记录 →「新增回款记录」 选择 JOB 后客户自动带入，款类来自付款条件；日期、金额独立填写，批次/制造番号严格限定在该 JOB，覆盖台数自动计算。
    修改待回收预警条件预警规则 可配置临近天数（默认 30）、金额容差（默认 0.01）、未验收/发票异常是否归④待确认；保存后重新「导出台账」生效。
    追溯新增/修改/删除审计记录 保存数据库后按操作人、JOB、业务表查询字段旧值和新值；legacy 历史不回填，审计启用后的变化会进入连续哈希链。
    看首页/待回收页效果摘要 + 导出台账 「导出台账」会从数据库重建导航页、未回收管理表、全部 JOB 页；摘要页先看校验问题。

    为什么“发货页面改无效、台账页面改有效”

    台账 JOB 页的设备行和批次列全部来自设备台账表；发货批次表只提供“出荷日”和自动汇总（台数/金额）。 所以：改批次归属 → 设备台账页改“发货批次”列（或发货批次页「✎ 重命名批次」）； 改出荷日 → 发货批次页。只改发货批次页的批次名、设备没跟着改，表格自然不显示。

    自动计算列（只读，别手改）

    五张子表的客户都由合同 JOB 自动关联。合同订单：设备型号、总台数、付款条件；设备台账：验收状态；发货批次：台数、金额合计、覆盖番号； 开票：覆盖台数、应收回款日、回款状态；回款：覆盖台数、对应应收日、超期标记/天数。编辑源字段后实时重算，保存时后端再次统一计算。

    待回收预警规则（改完点「保存数据」→「导出台账」生效）

    规则设置说明
    临近天数 天 应收回款日在 N 天内显示「②临近」并写入“临近”原因（默认 30 天）。
    金额容差 未回收金额 ≤ 容差视为「已回清」（默认 0.01）。
    未验收 → ④待确认 验收款未验收时不按日期判逾期，显示④待确认（默认开启）。
    发票异常 → ④待确认 开票状态不是「已开」或缺少应收回款日时归④待确认（默认开启）。
    质保款到期基准质保期满后 付款条件触发条件为「质保期满后」时，以覆盖设备最晚质保结束日 + 账期天数计算；未到期不判逾期，缺少质保结束日归④待确认。

    　首页/待回收页由「导出台账」从数据库自动重建，不需要手工改 Excel。

    说明

    · 保存数据库：在一个事务内校验并写入本地 .db；失败会整体回滚，写入前自动在 备份/ 保留数据库快照。
    · 旧 JSON 迁移：选择 *.records.json 时会在同目录创建 .db，原 JSON 保留不动。
    · 文件路径：只需选择或粘贴数据库路径；路径会保存为当前 Windows/macOS 用户的下次启动设置。
    · 单一数据源：数据库是唯一权威数据源，Excel 仅作为导出结果，不会从外部表格回写数据库。
    · 审计记录：新增、删除和实质字段修改与业务数据在同一事务写入；失败保存不会留下审计记录。请先设置正确的“当前操作人”。
    · 导出台账：按数据库重写同目录同名 xlsx（导航页 / 未回收管理表 / 各 JOB 页），旧版自动进同目录 备份/（留近 10 份）。
    · 检查更新：联网查 GitHub 最新 Release（仅 push 到 main 还不会产生可更新版本）；有新版可点「下载并打开」，解压到下载目录后，请退出本程序，用其中的新版本替换旧文件夹（未签名，首开仍需 Mac 右键打开 / Windows SmartScreen「仍要运行」）。
